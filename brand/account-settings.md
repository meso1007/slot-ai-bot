# LINE Official Account — 設定案（SLOT COMPASS）

## 基本情報
- **アカウント名**: `SLOT COMPASS`
- **プロフィール画像**: `assets/icon.png`（640×640 / 透明 / 青線）
- **カバー画像**: `assets/cover.png`（1080×878）
- **ステータスメッセージ**: `立ち回りの羅針盤。台の横で、3秒で判断。`
- **LINE ID**: `@slotcompass`（空いていれば。管理画面で設定）
- **業種カテゴリ**: 趣味・エンタメ（またはツール）

## 説明文（コピペ用）
```
SLOT COMPASS — パチスロの立ち回りを、その場で判断するリファレンス。

【メニュー】
・機種選択：台を切り替える
・評価：評判と概要
・スペック：天井・機械割
・狙い目：打ち始めの目安
・AT：AT中・上位AT
・終了後：AT後・ヤメ時

【その他】
・機種名を直接入力してもOK（例：炎炎の消防隊）
・わからないことは、そのまま質問
・「リンク」で設定示唆・フロー図の出典を表示

※参考情報です。最終判断は自己責任で。
```

設定場所: LINE Official Account Manager → Settings → Account settings → 基本情報/プロフィール の説明文。

## トーク設定
- **あいさつメッセージ（管理画面）**: OFF
  - コード側がLINEプロフィール名を取得し、「○○さん、初めまして！」を生成するため
- **応答メッセージ（自動応答）**: OFF
  - Webhook の bot が全メッセージを処理
- **Webhook**: ON
- **チャットバー**: `メニュー`

## 追加時の流れ（実装済み）
1. コード側テキスト: 「○○さん、初めまして！」＋SLOT COMPASSの説明＋使い方の箇条書き
2. コード側カード: 機種選択（人気順・最近使った台が先頭）
3. 管理画面のあいさつメッセージはOFF（二重防止）

挨拶文は `src/index.ts` の follow 分岐で変更できます。名前はLINEプロフィールの表示名を使用します。

## リッチメニュー（実装済み）
- 機種選択 / 評価 / スペック / 狙い目 / AT / 終了後
- chatBarText: `メニュー`
