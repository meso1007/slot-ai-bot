# SLOT COMPASS — Logo Brief

## Positioning
パチスロの立ち回りを、ホールで数秒で判断するためのリファレンス。
派手な期待煽りではなく、**静かに正確な判断道具**であること。

## Category codes
- 隣人: 解析サイト（ちょんぼりすた / DMMぱちタウン）、攻略アプリ、AIチャット
- 混雑している形: コンパス単体、チャット吹き出し、ロボット、リール/777
- 避ける: カジノ的な派手さ、AIっぽい青い球体・回路・吹き出し

## Brand nouns
compass / north / route / stance / read / timing / edge / signal

## Client decision tests（採点基準）
1. **16px** で読めるか（micro-mark）
2. **案内・判断ツール**に見えるか（カジノ広告に見えない）
3. 一般的なAI/チャット/コンパスの記号から**区別**できるか
4. **単色インク**で成立するか
5. 「compass / route」の**意味を所有**できるか
6. **エディトリアルで上質**か（安っぽくない）

## Tiebreaker
迷ったら要素を減らす。
