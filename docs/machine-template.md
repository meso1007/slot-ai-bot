# 機種データ テンプレート & 収集項目

新規機種を追加するときの共通規格。表示（Flexカード）・ルーティング・AI注入のすべてがこの構造に依存する。

## 1. ファイル規格

- 配置: `src/data/machines/{machine_id}.md`（例: `l_monkey_turn_5.md`）
- 1行目: `# 機種名: Lパチスロ モンキーターンV`
- 2〜3行目: 出典と注意書き（確認年月を必ず入れる）
- セクション順: `SUMMARY` → `SPEC` → `NORMAL` → `AT_CZ` → `AT_AFTER` → `EXIT_SETTING` → `REVIEW` → `SIMILAR` → `SOURCES`
- 項目は `- ラベル: 値` の1行1項目。`formatValue` が括弧外の `、。` で自動改行する
- 矢印は `→` を使わず、改行＋`↓` で表現する（表示変換はあるがmd上も統一）
- 数値は出典とセットで書く。不明は「不明」、推測は「推定」と明記する

## 2. セクション一覧

| セクション | 表示ラベル | 主なルーティング | 役割 |
| --- | --- | --- | --- |
| `SUMMARY` | 特徴 | 特徴 / どんな台 / 概要 / この台の | 台の要点を5行で把握 |
| `SPEC` | スペック | 純増 / コイン持ち / 出玉率 / 機械割 / 初当り / 確率 / 天井 / リセット / スルー | 数値の正本 |
| `NORMAL` | 通常時 | 通常時 / 前兆 / モード / 周期 / ゾーン / 狙い目 | 当選契機と狙い目 |
| `AT_CZ` | AT解説 | チャンスゾーン / CZ / AT / 上乗せ / 特化 | AT・CZ・上位ATの性能 |
| `AT_AFTER` | AT後 | AT後 / AT終了後 / 終了後 / 引き戻し / 上位示唆 / ツラヌキ | 終了後の追い条件 |
| `EXIT_SETTING` | ヤメ時 | ヤメ時 / やめ時 / やめどき / 終了画面 / 設定判別 | ヤメ時と設定判別 |
| `REVIEW` | 評価 | 評価 / 評判 / 口コミ / レビュー / 感想 | ユーザー評価と理由 |
| `SIMILAR` | 類似機種 | 似てる / 類似 / 近い台 / 他の台 / おすすめ機種 | ゲーム性が近い台 |
| `SOURCES` | （非表示） | なし（AIにのみ注入） | 出典URL |

## 3. 各セクションの収集項目

### SUMMARY（5項目固定）
- ゲーム性: タイプ・当選の流れを1文で
- メインAT: AT名・純増・上位ATの有無と性能
- 設定差: 出玉率の下限〜上限（設定1〜6）
- 天井: 通常時・リセット時の天井と恩恵
- 立ち回り: 狙い目・ヤメ時の要点

### SPEC（数値の正本）
- タイプ / メーカー / 導入日
- 純増（枚/G）※上位ATは別記
- コイン持ち（G/50枚）
- 初当り確率(AT): 設定1・2・4・5・6（設定3が公表されていれば追加）
- 出玉率: 設定1・2・4・5・6（%）
- 天井: ゲーム数＋周期・スルー回数
- リセット恩恵: 短縮後の天井・周期

### NORMAL
- 当選契機（周期・ポイント・レア役・直撃）
- 内部モードとそれぞれの天井・特徴
- ゾーン / 前兆 / 天井詳細
- 示唆演出（アイキャッチ等）と意味
- 狙い目ゲーム数（等価・非等価）

### AT_CZ
- チャンスゾーン（契機・期待度・成立役別抽選）
- メインAT（純増・継続方式・初期G・上乗せ契機）
- 上位AT / 特化ゾーン（突入条件・純増・継続率）
- ツラヌキ要素

### AT_AFTER
- AT終了後の挙動（有利区間リセット・引き戻し）
- 引き戻し / 上位AT示唆（終了画面・アイキャッチ）
- AT後1G目のレア役示唆
- 即移行率など設定差がある要素

### EXIT_SETTING
- 最適ヤメ時（即ヤメ条件・追う条件）
- 設定判別: 終了画面 / トロフィー / 小役 / 枚数表示 / タッチ等
- 各示唆の設定対応（偶数・高設定・設定6など）

### REVIEW（評価）
- 総合評価: `2.8/5（DMMぱちタウン 514件）` の形式
- 他サイト評価: `2.0/5（ちょんぼりすた 734件）、2.6/5（パチーモ 133件）`
- 良い点: 評価されている理由を1〜2文
- 気になる点: 不満・弱点を1〜2文
- ルール: 5点満点の `x/5` に統一。出典サイト名と件数・確認日を必ず添える。独自の平均値は作らない

### SIMILAR（類似機種）
- `- 機種名: 似ている理由` を2〜4台
- 理由は「周期抽選」「純増」「上位AT」「天井」「設定差」など具体的に
- 未検証の機種は載せない。前作・シリーズ作は「前作」と明記

### SOURCES
- `- サイト名「ページタイトル」 URL` の形式
- 2サイト以上。確認年月をファイル冒頭に記載

## 4. 表記ルール

- 確率: `1/299.8`
- 出玉率: `97.9%`
- 純増: `約2.5枚/G`
- 天井: `795G+α`、周期は `6周期`
- 設定: `設定1`〜`設定6`（欠番はそのまま。推測は「推定」）
- 評価: `2.8/5`（10点満点のサイトは換算せず、その旨を注記）
- 機種名は略さず正式名（`スマスロ 東京リベンジャーズ` 等）

## 6. 新規機種の追加手順

1. `src/data/machines/{machine_id}.md` を作成（下のスケルトン）
2. `src/data/index.ts` に import を追加し `MACHINES` に登録
3. `bunx tsc --noEmit`
4. `bunx wrangler deploy`
5. LINEで表示確認（各セクション＋キーワード）
